## 🚀 Panduan Publikasi ke GitHub Pages (Nilai Tambah Tugas)

1. Buka [GitHub](https://github.com) lalu buat repositori baru (misalnya `cv-maulana-raju`).
2. Unggah file `index.html`, `style.css`, folder `images/`, dan `README.md`.
3. Buka **Settings** -> **Pages** -> pilih branch **main**, folder **/ (root)** -> klik **Save**.
4. Website aktif Anda akan terbit di link: `https://username-anda.github.io/cv-maulana-raju/`.
5. Lampirkan link tersebut saat mengumpulkan file ZIP di **Edlink** sebelum pertemuan ke-4.
